# Briana Heredia — Portfolio

Personal portfolio site built to showcase my work and background as an aspiring software developer with [i.c.stars](https://icstars.org).

🔗 **Live site:** [b-heredia.github.io/portfolio](https://b-heredia.github.io/portfolio/)

## About

This is a single-page portfolio with three main sections:

- **About Me** — a short intro to who I am and what I'm learning
- **Projects** — showcases the projects I've built (in progress — more detail and real project write-ups coming soon)
- **Contact** — how to reach me

## Built With

- HTML5
- CSS3

## Getting Started

To run this locally:

```bash
git clone https://github.com/b-heredia/portfolio.git
cd portfolio
```

Then just open `index.html` in your browser — no build step or dependencies required.
